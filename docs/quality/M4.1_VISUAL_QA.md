## Scope

M4.1 offline-first sync shipped across backend and frontend:

- Dexie.js local DB (`entries`, `change_log`, `sync_meta`) — Sprint 3
- `POST /api/v1/sync/push`, `GET /api/v1/sync/pull` with LWW merge — Sprint 2
- `sync_conflicts` log + `GET /api/v1/user/sync-conflicts` — Sprint 1
- Local-first entry path, sync orchestrator, settings sync summary — Sprint 4
- Feature flag `canUseOfflineSync()` (verified users; default off without env/preference)

Surfaces under QA:

- Entry form (`/entries/new`, entry sheet) with offline sync enabled
- `SaveStatusBadge` offline states: `local`, `syncing`, `synced`, `offline`
- Neutral LWW conflict note on entry form
- Settings → App & offline (toggle, last push/pull, pending count, Sync now)
- PWA offline banner coexistence (shell cache unchanged; API not cached)
